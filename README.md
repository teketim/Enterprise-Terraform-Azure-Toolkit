# Enterprise Terraform Azure Toolkit

A hands-on portfolio repository focused on **enterprise Azure infrastructure, hybrid cloud architecture, disaster recovery, Infrastructure as Code, PowerShell automation, and operational resilience**.

The repository is organized into two tracks:

- **Labs** — focused exercises used to build individual Azure/Terraform skills.
- **Projects** — end-to-end portfolio solutions that combine architecture, automation, operations, documentation, risk management, and validation.

## Flagship Portfolio Project

### Project 01 — Enterprise Hybrid Azure DR & Automation

Design and automate a production-style disaster recovery architecture for a fictional enterprise migrating recovery capabilities from an on-premises VMware/Hyper-V environment into Microsoft Azure.

The project demonstrates:

- Microsoft Azure hybrid infrastructure design
- Hub-and-spoke networking
- Disaster recovery architecture and RPO/RTO planning
- Terraform modules and reusable Infrastructure as Code
- PowerShell workload-readiness assessment
- Azure Monitor / Log Analytics integration
- Recovery Services Vault design
- Migration risk analysis
- Failover, failback, rollback, and DR test planning
- GitHub Actions validation
- Operational documentation and architecture decision records

## Portfolio Goal

The objective is not simply to deploy Azure resources. Each project is built to demonstrate how a senior infrastructure engineer approaches:

1. Business and technical requirements
2. Architecture and design decisions
3. Infrastructure automation
4. Security and governance
5. Migration and operational risk
6. Validation and testing
7. Recovery and rollback
8. Production documentation
